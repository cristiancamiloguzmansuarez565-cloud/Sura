SURANS SEGUROS — PROYECTO FICTICIO
=================================

CONTENIDO
- index.html       Página pública de presentación y simulador.
- admin.html       Panel para crear, editar y eliminar productos.
- css/styles.css  Estilos responsivos y colores.
- js/app.js       Cálculos, catálogo y almacenamiento local.
- assets/         Carpeta disponible para imágenes propias.

CÓMO USAR
1. Extrae el ZIP en tu computador.
2. Abre index.html en un navegador.
3. Entra a admin.html para configurar los productos.
4. Cambia la tasa, el plazo, el nombre o los beneficios y guarda.
5. Regresa a index.html: el simulador y el catálogo tomarán los cambios.

FÓRMULA
Prima anual estimada = valor asegurado × tasa (%) / 100.
Prima mensual estimada = prima anual / 12.
Ejemplo: $4.000.000 × 7,5% = $300.000 anuales.

Los datos se guardan en localStorage del navegador. Para publicar el sitio,
sube la carpeta completa a tu hosting. La administración local no sincroniza
cambios entre dispositivos ni navegadores.

IMPORTANTE
Surans es una marca ficticia, independiente y sin afiliación con SURA ni
con otra aseguradora real. La plataforma es una demostración visual y
educativa: no emite pólizas, no recibe pagos, no ofrece cobertura real y
sus cifras, reseñas, beneficios y tiempos son ilustrativos.
